## Система одним абзацем

Один репозиторий, один владелец, без веток и PR. **По умолчанию всё автоматически**: гейт
и коммит происходят сами. Вручную говорятся два слова — и только они выпускают работу
наружу.

- Изменение готово → оно **проверено гейтом и закоммичено само** (`/finish`).
- Сказал **`push`** → гейт → `git push` → CI. Это **не** деплой.
- Сказал **`release`** → строгий гейт → CHANGELOG → версия → тег `vX.Y.Z` → CD сам
  прогоняет гейт ещё раз и катит на `server.zebaro.dev`.

Все проверки — через `scripts/gate.py`. Коммиты чистые и человеко-авторские. Два хука
(`guard-git`, `guard-secrets`) держат правила даже тогда, когда ни один скилл не вызывался.

## Карта обвязки

- **Скиллы** (`.claude/skills/`): сами → `/gate` · `/finish`; по слову → `/push` ·
  `/release` · `/prod` · `/idea`; служебные → `/approve-push` · `/playbook`
- **Агенты** (`.claude/agents/`): `explorer` · `code-reviewer` · `test-writer`
- **Хуки** (`.claude/hooks/`): `guard-git.py` · `guard-secrets.py` · `notify-windows.py`
  (тост Windows, когда задача закончена или есть вопрос)
- **Скрипты** (`scripts/`): `gate.py` · `release.py` · `approve.py` · `dev.bat` ·
  `prod.bat` · `start-claude.bat`
- **Настройки** (`.claude/settings.json`): разрешения, запрет читать `.env`, хуки и
  выключенная приписка к коммитам и PR (`attribution`)

## Где что лежит

- **Что делает бот** → `README.md`; **правила и раскладка кода** → `CLAUDE.md`.
- **Как здесь работать** → эта папка.
- **Что менялось для пользователя** → `CHANGELOG.md`.
- **Находки, которые ещё не задачи** → `_ideas/` (вне git, личное).
- **Черновики и мусор** → `_temp/` (вне git, выбрасываемое).
